# Typosaurus for Android

**[⬇ Download the latest typosaurus.apk](https://github.com/Akash-Gunasekar/typosaurus/releases/latest/download/typosaurus.apk)** (about 3 MB, Android 9 or newer)

## Install

1. Open the link above on your phone and download **typosaurus.apk**.
2. Tap the downloaded file. If Android asks, allow your browser or Files app to **install unknown apps**, then tap **Install**.
3. Open **Typosaurus**. Setup walks you through:
   - enabling the keyboard and selecting it,
   - accepting the privacy notice,
   - adding your API key (OpenAI, Anthropic, Groq, OpenRouter, Ollama Cloud or any OpenAI-compatible endpoint).
4. In any app, type something and tap ✨ on the keyboard.

## Check the download (optional)

Each release has a `SHA256SUMS.txt`. On a computer:

```bash
sha256sum typosaurus.apk
```

The value must match the line for `typosaurus.apk` in `SHA256SUMS.txt`.

## Updating

Download the newer APK from the [Releases page](https://github.com/Akash-Gunasekar/typosaurus/releases) and install it over the old one; your keys and settings are kept.
A copy installed from Google Play (once published) is signed differently, so switching between the two needs an uninstall first.
